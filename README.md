## Open the source code
1. Extract this ZIP to a normal folder.
2. Open `login.html` in Chrome/Edge to view the demo page.
3. Open the folder in VS Code to edit the HTML.
4. This is a front-end demonstration only; it does not authenticate users.

## Run the local Git demonstration
Install Git, then open a terminal in this folder and run:
- Windows PowerShell: `python run_git_demo.py`
- macOS/Linux: `python3 run_git_demo.py`

The script creates a separate `git_demo_repo` folder, initializes a local repository, creates two feature branches, demonstrates a merge conflict and resolution, and prints a commit graph. It does not create a GitHub repository or real Pull Requests.

## To complete the online GitHub part
Create a repository on your own GitHub account, push the feature branches, open PR 1 and PR 2, and replace the report's GitHub evidence placeholders with screenshots from your own repository. Never use the local demonstration output as proof that online PRs exist.
